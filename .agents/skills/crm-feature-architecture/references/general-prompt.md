# Prompt กลางสำหรับเพิ่มหรือแก้ feature ใน CRM

คัดลอกข้อความด้านล่างและเติมสิ่งที่ต้องการ หากมีเงื่อนไข UX หรือสิทธิ์เฉพาะให้เติมด้วย

```text
ฉันต้องการที่จะ ________________

ก่อนเขียนโค้ด ให้อ่าน AGENTS.md และใช้ skill crm-feature-architecture
ที่ .agents/skills/crm-feature-architecture/SKILL.md
รวมถึง skill เฉพาะ feature ที่เกี่ยวข้องถ้ามี

ตรวจโค้ดจริงก่อนเลือกโครงสร้าง ใช้ระบบเดิมที่เหมาะสมก่อนสร้างใหม่
แยกหน้าที่ของ UI, state, data และ server logic ให้ชัดเจน
ไม่รวม business logic ไว้ใน page/panel หรือย้ายไปกองใน hook ใหญ่อีกไฟล์
ไม่สร้าง abstraction หรือไฟล์เกินความจำเป็น

โหลดโค้ดและข้อมูลเมื่อจำเป็น ลด request ซ้ำ และรักษา UX, draft,
permissions และความถูกต้องของข้อมูล รวมถึง realtime หาก feature ใช้งาน
จัดการ pending, failure และ concurrent updates ตามความเสี่ยงจริงของงาน

ก่อนแก้ไข สรุปสั้นๆ ว่าจะเปลี่ยนไฟล์ใด แต่ละส่วนรับผิดชอบอะไร
และกระทบการโหลดข้อมูลอย่างไร แล้วดำเนินการต่อได้เลย
หาก skill ไม่ตรงโค้ดจริง ให้ระบุความคลาดเคลื่อนก่อนเลือกวิธีที่เหมาะสม

ก่อนจบ รัน checks ที่เกี่ยวข้องและตรวจพฤติกรรมที่เปลี่ยนจาก implementation จริง
ไม่ปิด checks หรือปรับเกณฑ์เพียงเพื่อให้ผ่าน
รายงานผลตรวจจริง ผลกระทบด้าน network ที่วัดได้หรือยังไม่ได้วัด และข้อจำกัด
```
