## 1. ปุ่มลัดหลักระดับระบบและการนำทาง (Global & Navigation)

| ปุ่มลัด (macOS) | ปุ่มลัด (Windows / Linux) | ฟังก์ชันการทำงาน | รายละเอียดเพิ่มเติม |
| :--- | :--- | :--- | :--- |
| <kbd>F</kbd> | <kbd>F</kbd> | **Menu Search** (ค้นหาเมนู) | กดเพื่อเปิดหน้าต่างค้นหาเมนูและฟังก์ชันทั่วทั้งระบบทันที |
| <kbd>⌘</kbd> + <kbd>K</kbd> | <kbd>Ctrl</kbd> + <kbd>K</kbd> | **Global Search** (ค้นหาด่วน) | คำสั่งมาตรฐานสากลสำหรับเรียกกล่องค้นหาเมนู |
| <kbd>/</kbd> | <kbd>/</kbd> | **Sidebar Search** | โฟกัสไปยังช่องค้นหาบนแถบเมนูด้านข้าง (Sidebar) |
| <kbd>Esc</kbd> | <kbd>Esc</kbd> | **Cancel / Close All** (ยกเลิก / ปิด) | ปิดหน้าต่าง Modal, Drawer, กล่องค้นหา, หรือแถบสไลด์ที่เปิดอยู่ทั้งหมด |

> [!NOTE]
> คีย์ลัดตัวอักษรเดี่ยว (เช่น <kbd>F</kbd> หรือ <kbd>/</kbd>) จะทำงานเมื่อเคอร์เซอร์ไม่ได้อยู่ในช่องกรอกข้อความ (`<input>`, `<textarea>`, `<select>`) เท่านั้น เพื่อป้องกันการพิมพ์ตัวอักษรโดยไม่ตั้งใจ

## 2. การค้นหาและนำทางบอร์ดไปป์ไลน์ (Pipeline Board & Card Navigation)

ปุ่มลัดสำหรับใช้งานบนหน้ารายการไปป์ไลน์ (`/pipeline`) ทั้งมุมมองบอร์ดปัจจุบัน (Workspace) และคลังประวัติ (Completed/Archived)

| ปุ่มลัด | ฟังก์ชันการทำงาน | รายละเอียดการทำงาน |
| :--- | :--- | :--- |
| <kbd>S</kbd> *(หรือแป้นไทย <kbd>ห</kbd>)* | **Page Search** (ค้นหาการ์ดในหน้า) | ขยายกล่องค้นหาการ์ดอัตโนมัติ พร้อมโฟกัสเคอร์เซอร์ให้พิมพ์ชื่อลูกค้าหรือชื่อดีลได้ทันที |
| <kbd>Esc</kbd> | **Clear & Close Search** | ล้างคำค้นหาและหุบกล่องค้นหากลับสู่สถานะเดิม |
| <kbd>↓</kbd> (ลูกศรลง) | **Select Next Card** | เลือกการ์ดถัดไปในคอลัมน์สเตจเดียวกัน (หากยังไม่มีการเลือกการ์ด จะเริ่มเลือกการ์ดใบแรกสุด) |
| <kbd>↑</kbd> (ลูกศรขึ้น) | **Select Previous Card** | เลือกการ์ดย้อนขึ้นไปด้านบนในคอลัมน์สเตจเดียวกัน |
| <kbd>→</kbd> (ลูกศรขวา) | **Next Stage Column** | เลื่อนการเลือกการ์ดไปยังสเตจถัดไปทางขวา พร้อมเลื่อนหน้าจอบอร์ด (Auto-scroll) ไปยังสเตจนั้น |
| <kbd>←</kbd> (ลูกศรซ้าย) | **Previous Stage Column** | เลื่อนการเลือกการ์ดไปยังสเตจก่อนหน้าทางซ้าย พร้อมเลื่อนหน้าจอบอร์ด (Auto-scroll) ไปยังสเตจนั้น |
| <kbd>Enter</kbd> | **Open Selected Card** | เปิดดูรายละเอียดการ์ดที่กำลังเลือกอยู่ เข้าสู่หน้าต่าง Deal Panel (แท็บกิจกรรม) ทันที |
| <kbd>Esc</kbd> | **Deselect Card** | ยกเลิกการเลือกการ์ดบนบอร์ด |

## 3. การควบคุมการ์ดด้วยเมาส์และคีย์ลัด (Kanban Card Smart Clicks)

การใช้งานเมาส์ร่วมกับปุ่ม Modifier บนการ์ดไปป์ไลน์ (Kanban Card):

```
+-----------------------------------------------------------+
| [ รูป Avatar ผู้รับผิดชอบ (Owner) ]                       |
|   - คลิกซ้ายปกติ          -> เปิดเข้าสู่แท็บ Collaborate  |
|   - Command + คลิกซ้าย    -> สลับตัวกรอง (Filter by Owner)  |
+-----------------------------------------------------------+
| [ ป้ายชื่อลูกค้า / บริษัท (Account / Customer) ]          |
|   - คลิกซ้ายปกติ          -> เปิดข้อมูลลูกค้า / โน้ต       |
|   - Command + คลิกซ้าย    -> กรองการ์ดตาม Account นั้น      |
+-----------------------------------------------------------+
| [ พื้นที่ตัวการ์ดโดยรวม ]                                 |
|   - คลิกซ้ายปกติ          -> เปิดหน้าต่างดีล (Deal Panel)   |
+-----------------------------------------------------------+
```

### 🎯 1. การกรองการ์ดตามเจ้าของงาน (Filter by Owner)

* **คำสั่งบน Mac**: กดปุ่ม <kbd>Command ⌘</kbd> ค้างไว้ แล้ว**คลิกซ้าย**ที่รูป Avatar ผู้รับผิดชอบบนการ์ดดีล
* **คำสั่งบน Windows/Linux**: กดปุ่ม <kbd>Ctrl</kbd> ค้างไว้ แล้ว**คลิกซ้าย**ที่รูป Avatar ผู้รับผิดชอบบนการ์ดดีล

#### พฤติกรรมการทำงาน:
1. **คลิกครั้งที่ 1 (Filter)**: ระบบจะกรองการ์ดบนกระดานทั้งหมด แสดงเฉพาะการ์ดที่บุคคลท่านนั้นเป็นผู้รับผิดชอบ (Owner) และแสดงวงแหวนไฮไลต์สีขาวรอบ Avatar
2. **คลิกซ้ำอีกครั้ง (Unfilter / Clear)**: ระบบจะยกเลิกการกรอง และแสดงการ์ดทั้งหมดบนกระดานตามปกติ

---

### 🏢 2. การกรองการ์ดตามชื่อลูกค้า / บริษัท (Filter by Account / Customer)

* **คำสั่งบน Mac**: กดปุ่ม <kbd>Command ⌘</kbd> ค้างไว้ แล้ว**คลิกซ้าย**ที่ป้ายชื่อลูกค้า/บริษัท (ด้านล่างซ้ายของการ์ด)
* **คำสั่งบน Windows/Linux**: กดปุ่ม <kbd>Ctrl</kbd> ค้างไว้ แล้ว**คลิกซ้าย**ที่ป้ายชื่อลูกค้า/บริษัท (ด้านล่างซ้ายของการ์ด)

#### พฤติกรรมการทำงาน:
1. **คลิกครั้งที่ 1 (Search / Filter)**: ระบบจะนำชื่อบริษัท/ลูกค้านั้นไประบุในช่องค้นหา (Page Search) บนบอร์ดทันที พร้อมแสดงเฉพาะการ์ดของลูกค้ารายนี้ และแสดงวงแหวนไฮไลต์สีขาวรอบป้ายชื่อลูกค้า
2. **คลิกซ้ำอีกครั้ง หรือกดปุ่ม <kbd>Esc</kbd> (Clear Search)**: ระบบจะล้างคำค้นหาในช่องค้นหาออกทันที และนำการ์ดทั้งหมดกลับมาแสดงตามปกติ

## 4. การทำงานในหน้าต่างรายละเอียดดีล (Deal Drawer & Panel)

เมื่อเปิดหน้าต่างตรวจสอบและแก้ไขดีล (`EditDealPanel`):

| ปุ่มลัด | ฟังก์ชันการทำงาน | รายละเอียด |
| :--- | :--- | :--- |
| <kbd>T</kbd> *(หรือแป้นไทย <kbd>ะ</kbd>)* | **Type Mode** (โฟกัสกล่องพิมพ์) | กระโดดเคอร์เซอร์ไปยังช่องพิมพ์ข้อความทันที (กล่องใส่กิจกรรม/คอมเมนต์ หรือ Note) โดยไม่ต้องเลื่อนเมาส์ไปคลิก |
| <kbd>Tab</kbd> | **Next Sub-tab** | สลับแท็บย่อยไปข้างหน้า เช่น: <br>• กิจกรรม: `Activity` ➔ `System Logs` ➔ `Manager Call`<br>• สื่อและไฟล์: `Images` ➔ `Links` ➔ `Files`<br>• สรุป AI: `Summary View` ➔ `Prompt View` |
| <kbd>Shift</kbd> + <kbd>Tab</kbd> | **Previous Sub-tab** | สลับแท็บย่อยย้อนกลับมาทางซ้าย |
| <kbd>↓</kbd> (ลูกศรลง) | **Next Main Tab** | สลับไปยังแท็บหลักถัดไปในเมนูขวา (เช่น Activity ➔ Notes ➔ Collaborate ➔ Media) |
| <kbd>↑</kbd> (ลูกศรขึ้น) | **Previous Main Tab** | สลับกลับไปยังแท็บหลักก่อนหน้า |
| <kbd>Esc</kbd> | **Close Panel / Modal** | หากเปิดหน้าต่างย่อย (Lightbox, Invite, Transfer, Actions) จะปิดหน้าต่างย่อยก่อน หากไม่มีหน้าต่างย่อยจะปิด Deal Panel |

## 5. การดูรูปภาพขนาดใหญ่ (Media Lightbox)

ขณะรับชมรูปภาพแบบเต็มหน้าจอ (Image Lightbox Viewer):

| ปุ่มลัด | ฟังก์ชันการทำงาน |
| :--- | :--- |
| <kbd>→</kbd> (ลูกศรขวา) | เลื่อนไปยังรูปภาพถัดไป (Next Image) |
| <kbd>←</kbd> (ลูกศรซ้าย) | เลื่อนกลับไปยังรูปภาพก่อนหน้า (Previous Image) |
| <kbd>Esc</kbd> | ปิดหน้าต่างดูรูปภาพขนาดใหญ่ |

## 6. การแก้ไขข้อมูลและแบบฟอร์ม (Forms & System Management)

สำหรับการใช้งานระบบจัดการและแบบฟอร์มทั่วไป:

| ปุ่มลัด | บริบทการใช้งาน | ฟังก์ชันการทำงาน |
| :--- | :--- | :--- |
| <kbd>Enter</kbd> | การแก้ไขข้อความแบบรวดเร็ว (Inline Edit ชื่อผู้ใช้ / แผนก) | บันทึกข้อมูลที่แก้ไขทันที |
| <kbd>Esc</kbd> | การแก้ไขข้อความแบบรวดเร็ว (Inline Edit) | ยกเลิกการแก้ไขและคืนค่าเดิม |
| <kbd>↓</kbd> / <kbd>↑</kbd> | กล่องระบุที่อยู่อัตโนมัติ (Address Autocomplete) | เลื่อนเลือกรายการที่อยู่แนะนำ |
| <kbd>Enter</kbd> | กล่องระบุที่อยู่อัตโนมัติ (Address Autocomplete) | ยืนยันเลือกที่อยู่ที่ไฮไลต์ |
| <kbd>Esc</kbd> | กล่องระบุที่อยู่อัตโนมัติ (Address Autocomplete) | ซ่อนรายการแนะนำที่อยู่ |

## 7. ตารางสรุปคีย์ลัดฉบับย่อ (Quick Cheat Sheet)

```
========================================================================================
 ปุ่มลัด (Mac / Win)          การทำงาน                                    พื้นที่ทำงาน
========================================================================================
 [ S ]                        ค้นหาการ์ดในไปป์ไลน์ (Page Search)          หน้ารายการไปป์ไลน์
 [ F ] หรือ [ Cmd/Ctrl + K ]  ค้นหาเมนูและฟังก์ชันทั้งระบบ (Menu Search)   ทุกหน้าจอ
 [ Esc ]                      ยกเลิก / ปิดหน้าต่าง / เคลียร์การค้นหา        ทุกหน้าจอ
----------------------------------------------------------------------------------------
 [ ลูกศร ขึ้น / ลง / ซ้าย / ขวา ]  เลื่อนเลือกการ์ดข้ามสเตจและในคอลัมน์    บอร์ดไปป์ไลน์
 [ Enter ]                    เปิดการ์ดที่กำลังเลือกอยู่                   บอร์ดไปป์ไลน์
----------------------------------------------------------------------------------------
 [ Cmd/Ctrl + คลิกซ้าย ]      กรอง / ยกเลิกการกรองตาม Owner ของการ์ด     Avatar บนการ์ด
 [ คลิกซ้าย ]                 เปิดแท็บจัดการสมาชิก (Collaborate)           Avatar บนการ์ด
----------------------------------------------------------------------------------------
 [ Cmd/Ctrl + คลิกซ้าย ]      ค้นหากรองการ์ดตามชื่อลูกค้า / บริษัท (Account) ป้ายลูกค้าบนการ์ด
 [ คลิกซ้าย ]                 เปิดดูข้อมูลลูกค้า / โน้ต                    ป้ายลูกค้าบนการ์ด
----------------------------------------------------------------------------------------
 [ T ]                        กระโดดไปพิมพ์คอมเมนต์ / โน้ตทันที            หน้าต่างดีล (Deal Panel)
 [ Tab ] / [ Shift + Tab ]    สลับแท็บย่อย (Activity / Logs / Manager)    หน้าต่างดีล (Deal Panel)
 [ ลูกศร ขึ้น / ลง ]          สลับเมนูแท็บหลักด้านข้าง                    หน้าต่างดีล (Deal Panel)
----------------------------------------------------------------------------------------
 [ ลูกศร ซ้าย / ขวา ]         เปลี่ยนรูปภาพก่อนหน้า / ถัดไป               หน้าต่าง Lightbox ดูรูป
========================================================================================
```

> **คำแนะนำเพิ่มเติม**: เพื่อประสิทธิภาพการทำงานสูงสุด แนะนำให้เริ่มจากการใช้ปุ่ม <kbd>S</kbd> เพื่อค้นหา, ใช้ปุ่มลูกศรและ <kbd>Enter</kbd> ในการเปิดการ์ด, และกดปุ่ม <kbd>T</kbd> เพื่อพิมพ์บันทึกงานได้อย่างต่อเนื่องโดยไม่ต้องจับเมาส์
